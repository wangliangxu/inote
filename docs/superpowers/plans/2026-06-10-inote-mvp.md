# iNote MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable iNote desktop MVP for local Markdown vault browsing, editing, search, journal notes, and scoped LLM API plumbing.

**Architecture:** Tauri 2 provides the desktop shell and Rust backend commands. React + TypeScript provides a three-panel local-first UI. Markdown files remain the source of truth; an in-memory frontend index is used for the MVP, with Rust parsing and filesystem operations ready for a later SQLite cache.

**Tech Stack:** Rust, Tauri 2, React, TypeScript, Vite, CodeMirror 6, Vitest, Cargo tests.

---

## File Structure

- `package.json`: frontend scripts and dependencies.
- `index.html`: Vite entrypoint.
- `vite.config.ts`: React/Vitest configuration.
- `tsconfig*.json`: TypeScript configuration.
- `src/main.tsx`: React bootstrap.
- `src/app/App.tsx`: main app composition.
- `src/app/App.test.tsx`: frontend smoke tests.
- `src/app/styles.css`: application styling.
- `src/shared/types.ts`: shared frontend data types.
- `src/shared/fixtures.ts`: demo vault used before a real vault is opened.
- `src/shared/vault.ts`: frontend helpers for grouping/filtering/searching notes.
- `src/features/*`: UI panels for explorer, editor, calendar, search, settings, and LLM assistant.
- `src-tauri/Cargo.toml`: Rust crate and Tauri dependencies.
- `src-tauri/tauri.conf.json`: Tauri app config.
- `src-tauri/src/main.rs`: Tauri command registration.
- `src-tauri/src/markdown.rs`: frontmatter and note metadata parsing.
- `src-tauri/src/vault.rs`: filesystem vault operations.
- `src-tauri/src/llm.rs`: OpenAI-compatible request construction.
- `src-tauri/src/commands.rs`: command DTOs and Tauri command functions.
