# 优化实现与验收记录

本轮实现覆盖草稿与保存、移动与链接、索引、性能、Frontmatter、Agent、模块拆分、CI 和生产访问范围。

## 笔记保存和草稿

- `useNoteWorkspace` 保留同步的当前笔记引用；磁盘刷新通过 `mergeDiskNotes`／`mergeDiskDelta` 合并，脏笔记及磁盘上已删除的草稿继续保留。
- 保存携带原始 Markdown 的 SHA-256 版本。后台写入前校验磁盘版本；编辑期间发生的外部修改会拒绝覆盖。
- 发生冲突后可使用“检查文件”，选择重新载入磁盘内容，或保留本地草稿并在确认最新磁盘版本后保存。
- `acknowledgeSave` 只确认已提交的那一版编辑，保存期间的新输入继续标为未保存，并更新其磁盘基线。
- 草稿存放于当前笔记库的 `.inote/drafts.json`，200ms 防抖写入。启动恢复、切换笔记库和退出均使用同一串行队列。
- 退出流程处理所有脏笔记。关闭自动保存时先持久化草稿再询问是否退出；自动保存失败或关闭期间产生新输入时保留窗口。原生 Quit 请求也经过相同流程。

## 文件、附件与链接

- 文件写入使用同目录下唯一的临时文件及 `sync_all`；新建和移动目标使用不覆盖已有文件的持久化操作。
- 文件路径按组件校验，并核对已存在父目录的规范路径；笔记和图片写入均拒绝越出笔记库的符号链接。
- 移动保留附件的稳定位置，重写 Markdown 中的相对资源路径；同步更新已索引的入站 Markdown／Wiki 链接。代码块和行内代码不参与重写。
- 后端 `persistence` 模块统一提交文件、索引和 Agent 操作记录；数据库更新失败时恢复文件与相关链接。数据库事务与文件补偿是不同机制，没有声称跨文件系统和 SQLite 具备断电级原子事务。

## 索引和性能

- 监听器合并连续事件，350ms 静默后触发，连续写入最长等待 1 秒；内部数据库、临时文件和 Git 目录不触发刷新。
- 索引比较纳秒修改时间和文件长度；明确发生变动的文件始终重读，覆盖时间及长度相同的替换。
- 索引更新、删除和重建均使用事务；普通更新保留入站链接；新增目标、重命名及删除时重新解析相关链接结构。
- 普通保存仅重读受影响文件，解析链接时只读取路径／标题身份表，不扫描整个磁盘笔记库。
- 列表只获取元数据和短摘要，正文与原始 Frontmatter 按选中笔记读取。监听 IPC 返回变更和删除路径，前端保留未受影响的笔记对象。
- 搜索使用 200ms 防抖；已有 50 条全文匹配时跳过回退扫描，并统一限制结果数量。
- 编辑器和辅助功能独立懒加载，增加功能边界，避免编辑器异常影响整个工作区。

## Markdown 和 Agent

- Frontmatter 使用 YAML 文档解析／序列化，保留未知字段、嵌套数据和注释，支持列表标签、多行值、引号、反斜杠及 CRLF。
- 无效 YAML 仍可作为原始 Markdown 读取和保留草稿；后端拒绝用无效 Frontmatter 替换磁盘文件。
- Agent 一次提交所选操作的最终结果，保留整份审阅前的快照；空选择不会隐式应用全部操作。
- 操作事件、撤销快照、会话更新及审阅状态在同一个 Agent 数据库事务中保存。
- 撤销校验应用后的磁盘版本，拒绝覆盖后续编辑；新建笔记的撤销将文件放入回收站。
- 切换笔记或卸载组件时取消请求，并忽略旧请求回调。SSE 从字节缓存解码，支持跨分块中文、多个 data 行及没有末尾换行的事件。
- HTTP 客户端复用，连接超时 15 秒、读取超时 60 秒、总请求超时 180 秒。

## 维护和安全

- 拆出持久化工具、工作区设置、文件监听、正文加载、搜索、退出流程和 Agent 提交构建器。
- 增加真实异步行为测试，启用 TypeScript 未使用代码检查和 Rust Clippy；CI 覆盖前端构建及 macOS／Linux／Windows 后端检查。
- 生产 CSP 限制脚本、连接、对象和基础 URL。开发 CSP 仅为 Vite 的刷新预置代码允许内联脚本。
- 资源协议不再默认允许整个用户目录；运行时授权已打开的笔记库，并禁止其内部配置和 Git 目录。笔记库外的绝对路径图片需先导入库内。
- Vite／Vitest 和相关依赖更新到修复版本；选择器解析依赖固定到兼容调用方式的安全版本。Node 运行要求与当前测试依赖保持一致。

## 验证和基准

基准脚本：`src-tauri/examples/vault_benchmark.rs`。结果保存于 `docs/benchmarks/2026-10-23-vault.json`。使用 macOS arm64、debug 配置、每篇约 2KB 正文、2 个标签；搜索执行 20 次。数据用于本机后续比较，不等同于其他设备或正式发布构建的性能承诺。

本机完成前端行为测试、TypeScript 检查、生产前端构建、Rust 测试、Clippy 和格式检查。浏览器冒烟检查确认演示工作区、笔记列表、编辑器和 Agent 输入区可加载。跨平台工作流已配置，Windows／Linux 的实际结果以 CI 运行为准。

最终基线：前端 162 项测试、后端 88 项测试通过；macOS 桌面调试版本构建成功；npm 依赖审计为 0 个漏洞。

### 兼容性

已有索引和 Agent 数据库在打开时自动补充字段。旧的撤销记录没有应用后版本，不能安全验证后续修改，因此拒绝直接覆盖；原有快照仍保留。Node 支持范围见 `package.json`，安装请使用锁文件。
