# 左栏笔记封面

左栏卡片按内容选择预览：思维导图显示图形缩略图；普通笔记默认显示正文首张 Markdown 行内图片；没有图片或图片无法加载时显示文字摘要。搜索时保留匹配摘要，列表模式不受影响。

在普通笔记的「元数据 → 卡片封面」中选择：

- **自动使用首张图片**：从正文前 65,536 个字符范围内查找图片，跳过代码示例和 HTML 注释。
- **指定图片**：填写相对当前笔记目录的图片路径，或 HTTP / HTTPS 图片地址。包含空格的 Markdown 图片路径可用尖括号包裹。指定本地图片须处于笔记库允许访问的范围。
- **隐藏封面**：只显示文字摘要。

选择随笔记保存。对应 YAML 字段 `cover`：图片地址表示指定封面，`false` 表示隐藏，缺省或 `null` 表示自动。图片本身、缓存和预览数据不写入正文。

卡片滚动到附近后才加载图片，最多同时处理三张，生成不超过 320 × 200 像素的小图。使用限量内存缓存和浏览器可用时的 IndexedDB 缓存，最多保留 128 张；缓存有效期五分钟，笔记版本或图片地址变化时使用新缓存。外部图片需允许跨域读取；无法读取或生成小图时回退到摘要。嵌入的大型 data URL 不作为自动封面，转为笔记库附件后可使用。

索引仅向列表提供图片路径，不读取整篇笔记到前端。旧索引会自动补齐封面路径，完整笔记与思维导图数据不受影响。
