# 思维导图

点击标题栏的思维导图按钮，可新建导图或批量导入文件。请先在设置中打开本地笔记库。导入目标沿用当前分类，其他视图使用默认分类；每个文件创建一篇新笔记，重名时增加数字后缀，不改动源文件。

## 编辑与保存

- 顶部工具栏按视图、撤销重做、节点操作、缩放、属性及文件操作分组，图标悬停显示说明。可直接新增子节点／同级节点、折叠选中分支和编辑备注。
- 在「导图 / 大纲」中切换，单击节点文字即可就地编辑（键盘聚焦节点后也可按 F2）；Enter 确认、Shift+Enter 换行、Esc 取消，点击其他位置确认。一次确认对应一条撤销记录，输入内容即时同步到笔记，编辑中也可直接使用保存快捷键。右侧属性面板编辑备注和链接。
- 保存位于工具栏；导出菜单提供 JSON 完整备份、FreeMind、OPML 和 Markdown，并说明各格式的保留范围。重命名、移动、检查文件和删除收进「更多操作」。
- 添加子节点、同级节点，选择父节点调整层级，使用上移、下移调整同级顺序。
- 导图采用紧凑的彩色曲线分支、灰色常规字重文字、自动换行及圆角中心主题卡片，浅灰画布衬托中心主题；导入文件中的颜色优先保留；无颜色的分支自动配色并向子节点继承。
- 父节点的连接点自动对齐最上方和最下方直接子节点连接点的中间位置，换行、编辑和折叠后重新计算。折叠分支、缩放及滚动浏览画布；支持多个顶层主题。打开时保留可读的缩放比例，点击「适应画布」查看全图。
- 「节点属性」面板默认关闭，可通过工具栏开关；开关选择保存在当前设备，下次打开导图或重启应用后恢复。导图视图会收起未使用的 AI 侧栏，切回普通笔记时恢复原侧栏偏好。
- 画布聚焦后，Tab 添加子节点，Enter 添加同级，Delete / Backspace 删除分支；Ctrl / Cmd + Z 撤销，Shift + Ctrl / Cmd + Z 重做。文本框保留原生键盘行为。
- 编辑后使用「保存」或应用的保存快捷键。节点结构、备注、颜色和折叠状态会随笔记保存；视图、缩放、选中节点及撤销历史不持久化。
- 未保存草稿、外部文件冲突、重命名、移动、标签、搜索及回收站沿用笔记流程。导图笔记暂不提供 AI 编辑。

## 导入格式

| 格式                             | 支持范围                                                                                                                          |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| FreeMind `.mm`                   | 多层节点、顺序、ID、文字、备注、链接、颜色、折叠；富文本转纯文本                                                                  |
| OPML `.opml`                     | 多主题、多层大纲、文字、备注（`_note` / `note`）、链接（`htmlUrl` / `url`）                                                       |
| iNote `.inote-mindmap` / `.json` | 本模块导出的版本 1 数据，完整恢复支持的节点属性                                                                                   |
| MindNode `.mindnode`             | 桌面版直接读取 Classic 内部格式 6 / 9：文件包、ZIP 单文件、XML / 二进制 plist；文字、层级、顺序、备注、链接、折叠及可识别的边框色 |

导入前显示文件名、节点数量和兼容提示；确认导入后保留逐文件结果。某个文件保存失败会停止队列，可重试剩余文件，已经成功的文件不会重复导入。格式错误的文件会跳过。

图片、图标、自由布局、跨节点关联线及其他未支持的样式不会迁移，界面会提示相关降级。原文件保持不变，请保留以便核对。FreeMind / OPML 当前读取 UTF-8 文件，不接受 XML DTD 或自定义实体；MindNode 额外支持二进制 plist 及标准 plist XML（允许标准 plist doctype，拒绝自定义实体）。每个文件最多 10 MiB、5000 个节点、64 层；每批最多 100 个文件。

## MindNode 原生直导

在桌面版的「选择文件」中选取 `.mindnode` 文件；若系统把文件包显示为普通目录，可使用「选择 MindNode 文件包目录」。读取器仅访问选中文件包内的 `contents.xml`，或单文件内的对应文档，整个过程不修改源文件。ZIP 只在内存中读取文档，不解压写入磁盘；压缩后的文件及解压后的文档各限制为 10 MiB。

当前明确支持内部格式 **6 和 9**，不等同于应用版本号。版本 6 已通过用户提供的实际旧文件验证；版本 9 按公开结构实现并用构造样本测试，更多实样本仍有助于扩大兼容覆盖。对于其他版本或无法识别的封装，显示原因，避免静默导入空导图。

节点 HTML 文字与备注转为纯文本，保留段落换行；HTML 链接提取为节点链接，多个链接时将额外地址保存在备注。附件、任务、节点标签、边界、跨节点连线及精确布局暂不迁移，会显示对应提示。浏览器预览不解析原生文件，请在桌面版导入，或继续使用 FreeMind / OPML。

## 导出

- **iNote JSON**：完整备份当前支持的节点属性，适合恢复或迁移到其他 iNote 笔记库。
- **FreeMind**：保留层级、文字、备注、链接、颜色和折叠；多个顶层主题会归入一个额外的中心主题。
- **OPML**：保留层级、文字、备注和链接，不保留颜色及折叠。
- **Markdown**：可阅读的大纲，作为内容交换格式；完整恢复请使用 JSON。

桌面版使用原生文件选择及保存对话框；浏览器预览使用文件上传及下载。

## 文件结构

每篇导图仍是普通 `.md` 文件，YAML frontmatter 的 `inote_mindmap` 保存唯一的节点结构：

```yaml
inote_mindmap:
  version: 1
  roots:
    - id: stable-node-id
      text: 中心主题
      children: []
```

节点还可包含 `note`、`link`、`color` 和 `collapsed`。正文是编辑导图时自动生成的 Markdown 大纲，用于搜索、摘要和外部阅读。外部编辑请修改结构数据；单独修改生成的大纲不会改变导图，下一次导图编辑会重新生成大纲。未知版本或损坏结构会显示错误，可进入现有 Markdown 源码编辑器修复。

## 验证

前端测试覆盖格式往返、中文和 XML 转义、备注及链接、Markdown 保存重开、大小和树深限制、重复 ID、循环移动保护、节点编辑、撤销重做、外部修改、键盘导航及批量导入失败重试。Rust 测试覆盖选中文件后的限量读取、UTF-8 解码和错误处理。文件对话框本身需在桌面端手动验收。

本地样本验收可设置 `INOTE_MINDNODE_SAMPLE` 后运行 `cargo test --manifest-path src-tauri/Cargo.toml --locked mindnode::tests::verify_local_sample -- --ignored --nocapture`。可选 `INOTE_MINDNODE_PAYLOAD` 将中间结果写入指定临时文件，供前端转换测试使用；不会把私人课程内容加入仓库。
