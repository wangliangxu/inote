# 思维导图

点击标题栏的思维导图按钮，可新建导图或批量导入文件。请先在设置中打开本地笔记库。导入目标沿用当前分类，其他视图使用默认分类；每个文件创建一篇新笔记，重名时增加数字后缀，不改动源文件。

## 编辑与保存

- 在「导图 / 大纲」中切换，点击节点，在右侧编辑文字、备注和链接。
- 添加子节点、同级节点，选择父节点调整层级，使用上移、下移调整同级顺序。
- 折叠分支、缩放及滚动浏览画布；支持多个顶层主题。
- 画布聚焦后，Tab 添加子节点，Enter 添加同级，Delete / Backspace 删除分支；Ctrl / Cmd + Z 撤销，Shift + Ctrl / Cmd + Z 重做。文本框保留原生键盘行为。
- 编辑后使用「保存」或应用的保存快捷键。节点结构、备注、颜色和折叠状态会随笔记保存；视图、缩放、选中节点及撤销历史不持久化。
- 未保存草稿、外部文件冲突、重命名、移动、标签、搜索及回收站沿用笔记流程。导图笔记暂不提供 AI 编辑。

## 导入格式

| 格式                             | 支持范围                                                                    |
| -------------------------------- | --------------------------------------------------------------------------- |
| FreeMind `.mm`                   | 多层节点、顺序、ID、文字、备注、链接、颜色、折叠；富文本转纯文本            |
| OPML `.opml`                     | 多主题、多层大纲、文字、备注（`_note` / `note`）、链接（`htmlUrl` / `url`） |
| iNote `.inote-mindmap` / `.json` | 本模块导出的版本 1 数据，完整恢复支持的节点属性                             |
| MindNode `.mindnode`             | 原生格式暂不直接支持；请在 MindNode 中导出 FreeMind 或 OPML 后导入          |

导入前显示文件名、节点数量和兼容提示；确认导入后保留逐文件结果。某个文件保存失败会停止队列，可重试剩余文件，已经成功的文件不会重复导入。格式错误的文件会跳过。

图片、图标、自由布局、跨节点关联线及其他未支持的样式不会迁移，界面会提示相关降级。原文件保持不变，请保留以便核对。当前读取 UTF-8 文件；不接受 XML DTD 或自定义实体。每个文件最多 10 MiB、5000 个节点、64 层；每批最多 100 个文件。

## 导出

- **iNote JSON**：完整备份当前支持的节点属性，适合恢复或迁移到其他 iNote 笔记库。
- **FreeMind**：保留层级、文字、备注、链接、颜色和折叠；多个顶层主题会归入一个额外的中心主题。
- **OPML**：保留层级、文字、备注和链接，不保留颜色及折叠。
- **Markdown**：可阅读的大纲，作为内容交换格式；完整恢复请使用 JSON。

桌面版使用原生文件选择及保存对话框；浏览器预览使用文件上传及下载。

## 文件结构

每篇导图仍是普通 `.md` 文件，YAML frontmatter 的 `inote_mindmap` 保存唯一的节点结构：

```yaml
inote_mindmap:
  version: 1
  roots:
    - id: stable-node-id
      text: 中心主题
      children: []
```

节点还可包含 `note`、`link`、`color` 和 `collapsed`。正文是编辑导图时自动生成的 Markdown 大纲，用于搜索、摘要和外部阅读。外部编辑请修改结构数据；单独修改生成的大纲不会改变导图，下一次导图编辑会重新生成大纲。未知版本或损坏结构会显示错误，可进入现有 Markdown 源码编辑器修复。

## 验证

前端测试覆盖格式往返、中文和 XML 转义、备注及链接、Markdown 保存重开、大小和树深限制、重复 ID、循环移动保护、节点编辑、撤销重做、外部修改、键盘导航及批量导入失败重试。Rust 测试覆盖选中文件后的限量读取、UTF-8 解码和错误处理。文件对话框本身需在桌面端手动验收。
